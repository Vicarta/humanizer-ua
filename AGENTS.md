# Правила роботи з репозиторієм

Після кожної зміни актуалізуй `README.md`, щоб він відповідав поточній
поведінці скіла, можливостям, встановленню та останньому релізу.
Публікуй оновлення README на GitHub разом із відповідними змінами.

Коли додаєш або редагуєш текст у `README.md`, завжди застосовуй скіл
`humanizer-ua` до нового або зміненого тексту.

Не описуй у `README.md`, як його текст редагували чи перевіряли через
`humanizer-ua`; це робоча вимога, а не частина документації продукту.

Не додавай до `README.md` розділи «Що нового», історію версій або блоки
приміток до релізів. Записуй зміни в `CHANGELOG.md` і GitHub Releases.
У README описуй поточні можливості продукту, встановлення та використання.
